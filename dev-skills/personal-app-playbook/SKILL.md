# 個人開発の進めかた

1 人で作る。**レビューしてくれる他人がいない**という前提から全部が決まる。
人の目の代わりを機械に置く。置けないものは作らない。

## 最初の 3 つの決定

これを先に決める。あとから変えると全部に波及する。

### 1. コンパイラに仕事をさせる言語を選ぶ

理由が無ければ Rust か TypeScript。**1 人だと「動くけど間違っている」を
見つける人がいない**ので、型検査で落ちるぶんだけ得をする。

- 計算の中核 … Rust (`#![forbid(unsafe_code)]`)
- 画面 … TypeScript (`strict` + `noUncheckedIndexedAccess` +
  `exactOptionalPropertyTypes`)。ESLint は型情報を使う `strictTypeChecked`
- 繋ぎのスクリプト … 言語を増やさない。Node か Bash のどちらかに寄せる

### 2. 配布の形を先に決める

**後から「1 枚 HTML にしたい」と言い出すと、依存の取り方から作り直しになる。**
最初に決めて、E2E で毎回検査する ([single-file-web-app](../single-file-web-app/))。

### 3. 「計算はどこで回るか」を決める

man-hour-calculator ではこれを**クライアント固定**にした。サーバはデータの
置き場所と権限だけを見る。結果:

- サーバを増やさずに人数が増やせる
- オフラインで動く性質が保てる
- Lambda に載せても数 ms で終わる (月 $5 に届かない)

計算をサーバに移した瞬間に、この 3 つが全部消える。**移せる設計にしておいて、
移さない。**

## 作る順序

飛ばすと後で高くつく順に並べてある。

| 段 | 作るもの | 終わったと言える条件 |
|---|---|---|
| 0 | リポジトリの骨 | `AGENTS.md` が書けている ([agent-ready-repo](../agent-ready-repo/)) |
| 1 | 計算コア + 1 枚 HTML | ダブルクリックで動き、E2E が外部通信 0 件を見張る |
| 2 | CI の下 3 段 | fmt / lint / 型 / 単体テストが PR ごとに回る |
| 3 | API 層を切る | 権限と不変条件が**1 か所**にある ([one-core-three-targets](../one-core-three-targets/)) |
| 4 | サーバ版 | バイナリ 1 つで建ち、埋め込んだ画面を配る |
| 5 | 検証の段を上げる | Kani / TLA+ / miri ([verification-ladder](../verification-ladder/)) |
| 6 | リリース | タグ push でクロスプラットフォームに配る ([release-supply-chain](../release-supply-chain/)) |
| 7 | クラウド版 | **先に設計文書だけ書く。** 実装は要求が出てから |

段 7 を「文書だけ」で止めたのが効いた。`docs/AWS.md` に DynamoDB の
テーブル設計と楽観ロックの手順まで書き下したことで、**段 3-4 の設計が
その形に耐えるか**を早い段階で検査できた。実装は 1 行も書いていない。

## 1 人でやるときに効いた装置

| 装置 | 代わりをしているもの |
|---|---|
| 型 + smart constructor | 「その値、本当に不変条件を満たしてる?」というレビューの指摘 |
| Kani / TLA+ | 「その順序で操作したらどうなる?」という指摘 |
| ミューテーションテスト | 「そのテスト、何も確かめてないよ」という指摘 |
| Store 適合テスト | 「2 つの実装で挙動違ってない?」という指摘 |
| `check-sync.sh` | 「文書が古いままだよ」という指摘 |
| Dev Container + CI | 「自分の環境では動くんだけど」の再発防止 |

**全部「1 人では思いつかないこと」を見つけるためのもの。** カバレッジや
lint のような「書いたものが正しいか」の道具とは目的が違う。

## やらないと決めたこと

決めて書いておくと、迷ったときに戻ってこられる。

- **計算をサーバに移さない**
- **`Service` を非同期にしない** (WASM まで async が波及する)
- **Rust の依存クレートをコアに足さない** (コアと API は `serde` だけ)
- **外部へ通信を増やさない** (アイコン・フォント・画像を CDN から取らない)
- **`innerHTML` を使わない**

`docs/` に「やらないこと」の節を作って書く。**Claude に渡す `AGENTS.md` にも
同じものを書く。** 書いていないものは、次のセッションで平気で足される。
