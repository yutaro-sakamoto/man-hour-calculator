# 取り決めそのものを書くとき

ここは**貯まっていく場所**。[AGENTS.md](../../AGENTS.md)「学んだことを持ち越す」の
段 2 の行き先で、[docs/JOURNAL.md](../../docs/JOURNAL.md) から昇格してくる。

貯まること自体は良い。困るのは**貯まったまま腐る**こと。指し先の消えたフック、
当たるファイルの無い rules、名前のずれた agent — どれも壊れていても何も
起きないので気づけない。`./scripts/check-sync.sh` がそこを見ている。
**足したら回す。**

雛形は自分で書かなくてよい。

```sh
./scripts/journal.sh promote rules <名前>      # .claude/rules/<名前>.md
./scripts/journal.sh promote command <名前>    # .claude/commands/<名前>.md
./scripts/journal.sh promote agent <名前>      # .claude/agents/<名前>.md
```

## どこに書くか

| 置き場所 | 効く範囲 | 迷ったら |
|---|---|---|
| `AGENTS.md` | 全体。**毎回読まれる** | ここは短く保つ。3 行で言えないなら rules へ |
| `.claude/rules/*.md` | `paths:` に当たるものを触ったときだけ | **既定はこちら** |
| `.claude/commands/*.md` | 呼ばれたときだけ | 「この手順は毎回やる」と思ったら |
| `.claude/agents/*.md` | 撒かれたときだけ | 読むだけの仕事を切り出すなら |

`AGENTS.md` を伸ばすほど、全部が読み飛ばされる。**範囲を絞れるものは rules へ。**

## 禁止には理由を添える

理由の無い禁止は、次のセッションで「より良い方法」に置き換えられる。

> **`innerHTML` を使わない。** 名前もコメントも利用者が書いた文字列で、
> そこに何が書かれていてもスクリプトになってはいけない

**踏んだ事実ごと書く。** 「〜に注意」より「〜で 2 時間溶かした」のほうが効く。
`.claude/rules/permissions.md` の「過去に見つかった穴」がいちばん効いている節。

## フックは黙っているのが基本

- **何も言うことが無ければ、何も出さない。** 毎回口を出すと読まれなくなる
- **モデルを使わない。** `grep` と `awk` で済む範囲にする。費用も時間もかからない
- **止めない。** `additionalContext` を出すだけ。作業の途中で一時的にずれるのは
  ふつうのことで、止めると邪魔になる
- 閾値で黙らせているものは、**閾値を超えたときの出力を実際に見て**から入れる

フックは 1 つの `Stop` に並べて足せる。どれも黙っているのが既定でないと、
数が増えた時点で全部読み飛ばされる。

## `settings.json` の 3 つの箱

| | 何を入れるか |
|---|---|
| `allow` | **検査のコマンド。** 毎回聞かれると、検証そのものを省くようになる |
| `ask` | **外に出るもの。** merge / release / push |
| `deny` | **取り返しのつかないものと秘密。** force push、`.env` |

`allow` に名指ししたスクリプトの名前を変えたら、許可は黙って外れる。
`check-sync.sh` が実在を見ている。

## 多バイト文字の隣で、ロケールに頼らない

語境界 (バックスラッシュ b) は、多バイト文字の直後ではロケールで意味が変わる。
`LANG` が未設定の環境では境界が成立せず、**当たらないまま静かに 0 件を返す**。
数える検査がこれで丸ごと死んでいた。`check-sync.sh` が見ている。

`grep -oP` の `\K` と `\S` は使ってよい (バイト単位で動くので結果が変わらない)。

## 「0 件」を「無い」と読まない

同じ種類の失敗が 2 度あった。どちらも**エラーにならず、何も当たらないまま
0 件を返し、「問題なし」に見えた。**

- 多バイト文字の直後の語境界 (上の節)
- `-` で始まるパターンを `grep` にそのまま渡した。引数と読まれて何も探さない。
  パターンは必ず `grep -e "$pattern"` で渡す

検査を足したら、**わざと破ったものを置いて赤くなることを確かめる**。
0 件が正しいのか、見ていないだけなのかは、それでしか分からない。
