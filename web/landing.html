Effort Estimator

工数見積もり

Work in progress. This project is still under development. Things move around, saved files may stop loading, and nothing here is ready to rely on.

開発中です。 このプロジェクトはまだ作っている途中です。作りが変わることも、保存したファイルが読めなくなることもあります。 そのまま業務で頼れるものではありません。

Turns three-point estimates into a probability distribution of total effort — and a date the work is likely to finish.

3 点見積もりから、総工数の確率分布と、仕事が終わりそうな日を求めます。

The computation core is Rust compiled to WebAssembly. The whole tool is one HTML file that works offline.

計算コアは Rust を WebAssembly にしたもの。ツール全体が 1 枚の HTML で、オフラインでも動きます。

Try it now すぐに試す Download the file ファイルを保存する Source ソース

This opens the local version. Everything runs in your browser and stays there — no account, no server, no network requests. What you enter is kept in this browser's storage, so it is gone if you clear site data or switch devices. Use the file export to keep a copy. To share work across people, run the server (below).

開くのはローカル版です。すべてブラウザのなかで動き、外には出ません (アカウントもサーバも通信もありません)。入力した内容はこのブラウザに保存されるので、 サイトデータを消したり別の端末に移ったりすると無くなります。残したいときはファイルに書き出してください。 複数人で共有するにはサーバを建てます (下)。

What it does

できること

Distribution, not a single number

1 つの数字ではなく分布

Enter minimum / most likely / maximum per task. Two independent engines — Monte Carlo and numeric convolution — compute the total and check each other.

タスクごとに最小・最可能・最大を入れます。モンテカルロと数値畳み込みという 2 つのエンジンが総工数を求め、互いの答え合わせをします。

Effort turned into dates

工数を日付に

People have their own working hours, holidays and meetings. The calendar turns effort into "who finishes what, on which day, with what probability".

人ごとに稼働時間・休日・予定があります。カレンダーが工数を「誰の何が、何月何日に、 どれくらいの確からしさで終わるか」に変えます。

Actuals fold back in

実績を織り込む

Start dates, progress and completion dates update the forecast. Progress shortens what is left; falling behind shows up as more total effort.

着手日・進捗率・完了日が見通しを更新します。進んだぶん残りは減り、遅れているぶん総工数は増えます。

Projects, people and comments

プロジェクト・人・コメント

Several projects at once, with groups and per-user permissions. Comments in Markdown on projects and tasks — people with view-only access can write them too.

複数のプロジェクトを、グループとユーザごとの権限つきで扱えます。プロジェクトとタスクには Markdown でコメントを書けます (閲覧のみの人も書けます)。

For a team

複数人で使う

One binary. SQLite and the web UI are inside it, so there is no database to set up and no web server to run beside it.

バイナリ 1 つです。SQLite も画面も中に入っているので、データベースを用意する必要も、 Web サーバを別に立てる必要もありません。 

cargo xtask build
cargo build --profile server -p mhc-server
./target/server/mhc-server

PostgreSQL works too. See SERVER.md.

PostgreSQL にも対応しています。 SERVER.md を参照してください。
