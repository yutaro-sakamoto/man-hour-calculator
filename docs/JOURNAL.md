# 開発日誌

踏んだ穴・読み違い・設計の判断を追記していく。新しいものが上。
雛形は `./scripts/journal.sh new "<要約>"`、Claude Code なら `/learn`。

**書くだけでは効かない。昇格させる。** `昇格:` は次の 5 つのどれか。

| 値 | 意味 |
|---|---|
| `未` | まだ何にもしていない。応答の終わりにフックが数えている |
| `rules` | [AGENTS.md](../AGENTS.md) か `.claude/rules/` に書いた |
| `機械` | テスト / lint / `scripts/check-sync.sh` にした。**ここまで来て初めて守られる** |
| `skill` | [dev-skills/](../dev-skills/) に移した |
| `一過性` | 上げる価値が無いと判断した。判断したことを残す |

段は**最初の語**。後ろに「どこに置いたか」を括弧で足してよい
(`昇格: 機械 (scripts/check-sync.sh)`)。

ふつうのバグは書かない。**直す前の実装では落ちる回帰テストを添えれば、
テストのほうが記録になる。**

迷ったら「この決めごとを破ったコードは `grep` で見つかるか」を考える。
見つかるなら `scripts/check-sync.sh` に足して `機械` にする。

## 2026-09-21 — `cargo mutants --shard 4/4` が落ちた

- 分類: ci / 環境
- 症状: 4 シャードのうち最後の 1 つだけが `shard k must be less than n` で落ちる
- 原因: `--shard` の添字は **0 始まり** (`k < n`)
- 手当て: matrix を `[0, 1, 2, 3]` にした
- 昇格: 機械 (`.github/workflows/mutants.yml`)

## 2026-09-21 — Windows のスモークテストでサーバが起動しなかった

- 分類: 環境 / リリース
- 症状: `windows-*` の target だけ、組んだバイナリが起動しない
- 原因: Git Bash の `mktemp -d` が返す `/tmp/...` は、Rust から見ると
  ドライブの無い読めない綴りになる
- 手当て: 保存先を**作業ディレクトリからの相対**にした
- 昇格: 機械 (`.github/workflows/release.yml` のスモークテスト)

## 2026-09-21 — 空の SBOM を配った

- 分類: リリース
- 症状: web の SBOM の `components` が 0 件のまま Release に添えられた
- 原因: `npm sbom` に `--omit dev` を付けた。この構成では依存が**すべて**
  ビルド時だけのもので、除くと中身が空になる
- 手当て: 付けずに全部出す。件数 0 なら落とす検査を足した。
  「何で組み立てたか」こそが知りたいこと
- 昇格: 機械 (件数の検査)

## 2026-09-21 — `apt` の binaryen で `wasm-opt` が検証に失敗した

- 分類: 環境 / ci
- 症状: `wasm-opt` が、rustc が既定で出す sign-ext 命令を弾く
- 原因: apt のものが古い。さらに、機能フラグを個別に並べると binaryen を
  上げ下げするたびに壊れる (`bulk-memory` が 2 つに分かれた、など)
- 手当て: 公式リリースを**版固定**で取り、`-Oz -all` で回す。
  CI では `--require-wasm-opt` を立て、最適化が静かに外れたまま配らないようにした
- 昇格: 機械 (`.devcontainer/Dockerfile`、CI、`xtask` の `require_wasm_opt`)

## 2026-09-21 — `cargo kani setup` が取得の 504 で落ちた

- 分類: ci / 環境
- 症状: Kani のジョブが日によって落ちる
- 原因: 取得先が 504 を返す。**Kani 自身の curl なので、こちらからフラグを

## 2026-09-21 — `MemoryStore` と `SqlStore` の挙動が違っていた

- 分類: 設計 / 検証
- 症状: 同じ操作で、ローカル版とサーバ版の応答が違う
- 原因: 保存先ごとにテストを書いていた。`MemoryStore` だけが件数を数え直し、
